# 고사리잇 (gosari-it)

제주에서 고사리 캐러 갈 때 쓰는 AI 도우미입니다. 날씨를 비교해 언제 어디로 갈지 고르고, 캔 기록을 남기고, 지인에게 나눈 내역과 시세를 확인합니다.

## 무엇을 할 수 있나요

| 메뉴      | 하는 일                                                                                   |
| --------- | ----------------------------------------------------------------------------------------- |
| 채팅      | 말로 물어보면 필요한 자료를 찾아 답합니다. 예: "내일 아침 애월이랑 성산 중 어디가 좋아?"   |
| 나들이    | 날짜·지역 후보를 2~4개 넣으면 비·기온·바람을 비교해 추천하고 준비물을 알려줍니다.          |
| 지역 탐색 | 지도에서 주소를 찾고 관심 장소를 핀으로 저장합니다. 주변 날씨도 같이 봅니다.              |
| 내 수첩   | 채취 기록을 쓰고 달력과 검색으로 다시 봅니다.                                              |
| 나눔      | 지인별로 나눈 양과 날짜를 기록합니다. 승인하면 텍스트 파일 1개로 내려받을 수 있습니다.     |
| 가격 조사 | 소매 가격, 지역 조사가, 도매 정산가를 보고 1kg 기준으로 비교합니다.                        |

마이크 버튼을 누르고 말하면 입력란에 글이 들어갑니다. 보내기는 직접 누릅니다.

가입 없이 바로 쓸 수 있고, 기록은 브라우저에 묶여 저장됩니다. 설정에서 아이디·비밀번호로 가입하면 그동안의 기록이 회원 기록이 되고, 다른 기기에서 로그인하면 그곳의 기록도 합쳐집니다.

날씨는 기상청 자료를 먼저 쓰고, 기상청 범위 밖이면 Open-Meteo를 씁니다. 도매 가격은 aT 실시간 조회입니다. 채팅 답변은 GPT-6 Luna가 만들지만, 숫자는 모두 서버가 실제 자료에서 가져온 값만 씁니다. 수첩·지인·나눔 같은 개인 기록은 이 컴퓨터에만 저장하고 외부 AI 모델에 보내지 않습니다.

## 시작하기

필요한 것: Docker, [mise](https://mise.jdx.dev), 기관 API 키(제주데이터허브·공공데이터포털·브이월드)와 OpenAI 키.

```sh
mise trust && mise install --locked
bun install && uv sync --all-packages
mise run init                      # apps/api/.env 를 만듭니다
# apps/api/.env 에 키를 적습니다 (.env.example 참고)
mise run up                        # 이미지 빌드 → DB → 앱 시작
```

브라우저에서 `http://127.0.0.1:8765` 을 엽니다.

| 명령                                         | 하는 일                              |
| -------------------------------------------- | ------------------------------------ |
| `mise run doctor`                            | Docker·포트·설정이 준비됐는지 확인   |
| `mise run status`                            | 컨테이너와 기능 가용성 확인          |
| `mise run logs`                              | 최근 로그 보기                       |
| `mise run down`                              | 앱 중지 (기록은 남음)                |
| `mise run reset -- --confirm=gosariit-local` | DB까지 모두 지우기                   |

키가 없으면 어떻게 되나요? 기관 키가 없으면 해당 조회는 표본 자료나 제한 모드로 동작합니다. OpenAI 키가 없으면 채팅 자유 대화는 안 되고 메뉴 기능만 씁니다. 자세한 설정은 [설치·운영 매뉴얼](docs/install-manual.md)에 있습니다.

개발자용: `mise run infra:up` → `mise run db:migrate` → `mise run dev` 로 API(8000)와 Vite(5173)를 따로 띄울 수 있습니다.
