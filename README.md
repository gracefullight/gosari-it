# 고사리잇 (gosari-it)

제주 고사리 채취 동행 AI 에이전트. 제주 날씨 비교, 경험 기록, 지인 나눔과 가격 확인을 채팅과 다섯 메뉴로 연결한다.

GPT-6 Luna가 대화 문맥에서 도구와 조회 조건을 선택한다. 서버가 기관 자료를 조회·검사·집계하며, 개인 기록 변경은 미리보기와 사용자 확인을 거친다.

## 기능

| 메뉴      | 기능                                                                                |
| --------- | ----------------------------------------------------------------------------------- |
| 채팅      | 문맥을 잇는 실제 도구 선택·SSE 답변, 후속 질문, 상세 결과·거리뷰·토지 소유 구분     |
| 나들이    | 날짜별 제주 날씨, 2~4개 지역·날짜·시각 후보와 비·기온·바람 우선순위 비교, 준비 목록 |
| 지역 탐색 | 주소 검색·관심 장소 핀·방문일·메모·주변 날씨                                        |
| 내 수첩   | 목록·달력·검색, 위치와 참고 자료를 포함한 작성·수정·삭제                            |
| 나눔      | 지인 관계와 사람별 나눔 이력, 날짜·분량·단위·예정/전달 완료                         |
| 가격 조사 | 소매·지역 조사가·도매 정산, 날짜·시장·생건·규격 필터, 상품/1kg 환산·조건별 캐시     |

결과는 ‘상세 보기’ 모달에서 확인한다. 모델이 등록된 화면 구성요소를 선택하고 서버가 실제 조회 결과를 연결한다. 거리뷰는 사용자가 클릭할 수 있는 링크를 만든다. 채팅에서 기록 검색과 작성 화면으로 이어갈 수 있다.

마이크로 말한 내용은 말이 끝나면 수정 가능한 입력란에 들어간다. 전송은 사용자가 누른다. 지원 브라우저의 한국어 인식과 실제 마이크 음량 파형을 사용하며 별도 언어팩 준비 화면은 없다.

## 빠른 시작

사전 구성: mise, Bun·Python 의존성, 로컬 Linux Docker 엔진. 자세한 설정과 환경별 확인 범위는 [설치 매뉴얼](docs/install-manual.md)을 따른다.

```sh
mise trust
mise install --locked
bun install
uv sync --all-packages
mise run init
# apps/api/.env에 기관·OpenAI 키와 외부 요청 설정을 입력
mise run up
```

`mise run up`은 이미지를 빌드하고 DB·migration·앱을 시작한다. 기본 접속은 `http://127.0.0.1:8765`다.

| 명령                                         | 동작                                          |
| -------------------------------------------- | --------------------------------------------- |
| `mise run doctor`                            | Docker·잠금 파일·포트·설정 확인               |
| `mise run init`                              | 없는 앱별 `.env` 생성, 기존 값 유지           |
| `mise run up`                                | 빌드 → DB → 초기화/migration → 앱 → readiness |
| `mise run status`                            | 컨테이너·기능 가용성 확인                     |
| `mise run logs`                              | 최근 운영 로그                                |
| `mise run down`                              | 컨테이너 정리, DB 볼륨 유지                   |
| `mise run reset -- --confirm=gosariit-local` | 공개 자료·개인 기록 DB 볼륨 삭제              |

API 설정은 `apps/api/.env`, 웹 설정은 `apps/web/.env`에서 관리한다. 실제 파일·API 키는 제출 소스나 이미지에 포함하지 않는다. 설정 예제는 각 앱의 `.env.example`에 있다.

### 네이티브 개발

```sh
mise run init
mise run infra:up
mise run db:migrate
mise run dev
```

API는 8000, Vite는 5173을 사용한다. 네이티브 DB 주소는 `127.0.0.1:15432`다. `infra:up`은 `compose.yaml`과 `compose.native.yaml`로 같은 `gosariit-local` DB·볼륨만 시작하며 빌드·pull·앱 재시작을 하지 않는다. `infra:down`은 같은 DB만 중지한다. 컨테이너 앱의 DB 주소는 `db:5432`이며 기본 Compose DB는 호스트에 공개하지 않는다.

## 실행 모드와 자료

`APP_PROFILE=replay`는 검증 표본 재생 경로다. 그 밖의 프로파일은 `EXTERNAL_REQUESTS_ENABLED`와 기관 키에 따라 실조회 또는 제한 모드가 된다. 자유 대화에는 OpenAI 키와 모델 전송 설정이 필요하며 모델 연결 실패는 오류로 표시한다. 개인 기록은 DB가 구성된 현재 세션에 저장한다.

제주 지도용 Open-Meteo, 지도 타일·주소 검색·브라우저 음성 인식은 별도 브라우저/지도 경로를 사용한다. 기관 게이트 하나를 전체 오프라인 전환으로 표현하지 않는다.

공개 정규화 조회와 응답 캐시는 PostgreSQL에 분리한다. 문맥 없는 같은 공개 질문은 첫 모델 호출 전에 캐시를 확인한다. 확정 조건의 의미 검색은 조건 일치와 유사도 `>0.95`, 버전·TTL·해시·품질 검사를 거친다. 개인 검색은 세션 안의 키워드 검색을 기본으로 하고 로컬 모델이 준비되면 의미 검색을 결합한다.

aT 도매 정산은 기관 실조회다. 산림조합 조사가와 소매 상품은 확인 시점이 있는 표본·공식 원문 링크를 제공한다. 기상청 관측, Open-Meteo 예보·과거 재분석, 표본 재생을 구분한다.

제출용 AMD64 이미지·격리 빈 DB 검증·소스 ZIP은 `submission:build:amd64`, `submission:verify`, `submission:stop`, `submission:package` 작업으로 구분한다. PDF·영수증 인자와 소유 자원 정리는 [설치 매뉴얼](docs/install-manual.md)의 제출 실행 절차를 따른다.

## 데이터 경계

- 저장된 수첩·지인·관심 장소·나눔 원문은 외부 LLM과 공용 캐시에 넣지 않는다. 모델에는 개인 검색의 종류·건수만 전달한다.
- 공개 관측 지점의 공식 좌표는 공개 자료이며 개인 핀과 구분한다.
- 개인 변경은 미리보기 → 확인 → 동의 → 실행으로 처리한다.
- 주소 검색·좌표 변환과 브라우저 음성 인식의 외부 요청 범위는 [데이터 활용 명세](docs/data-usage.md)에 있다.
