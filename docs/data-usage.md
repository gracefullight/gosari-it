## 수집·전처리 원칙

- 원 응답·정규화 자료·조회 조건·수집일·출처·행수·해시·처리 버전을 구분 보존한다.
- 원 필드와 품질표시를 유지하고 **숫자 0·결측·오류·의미 미확정 공란**을 구분한다.
- 같은 키의 동일 중복은 1회 집계, 충돌은 확인 대상으로 처리(자동 봉합 금지).
- 항목별 유효 범위와 공통 날짜를 계산한다. 강수 커버리지로 기온 커버리지를 대체하지 않는다.
- 가격은 종류·생/건·산지·단량·등급·배송·쿠폰 조건을 나눠 비교한다. 서로 다른 종류를 평균내지 않는다.
- 공개 CSV를 기관 원 JSON으로 표시하지 않는다.

## 개인정보·공개 경계

- 개인 기록(수첩·나눔·등록 지역)은 세션 메모리 한정. 공개 DB·캐시·로그·백업에 넣지 않는다.
- 공개 분석 DTO는 allowlist로 새로 작성하며 개인 별칭·기록 ID·원문·정확 좌표를 제외한다.
- 의미 캐시는 임베딩 **이전** 적격성 검사를 수행하고, 개인혼입 의심 시 우회한다.
- 공용 evidence는 누가 어떤 수첩에 연결했는지 알 수 없다(역매핑 금지).
