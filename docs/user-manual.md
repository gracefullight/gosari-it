# 고사리잇 사용 매뉴얼

고사리잇은 제주 날씨와 나들이 후보를 비교하고, 다녀온 곳과 지인에게 나눈 고사리를 기록하며, 가격을 확인하는 서비스다. 채팅에서 묻거나 메뉴를 직접 열 수 있다.

## 1. 화면과 메뉴

| 메뉴      | 주소            | 할 수 있는 일                                            |
| --------- | --------------- | -------------------------------------------------------- |
| 채팅      | `/`             | 질문·후속 대화, 공개 자료 조회, 기록 검색·작성 화면 열기 |
| 나들이    | `/outing`       | 날짜별 날씨와 후보 지역·시각 비교                        |
| 지역 탐색 | `/regions`      | 관심 장소 핀과 방문 날짜·메모 관리                       |
| 내 수첩   | `/notebook`     | 기록 목록·달력·검색                                      |
| 수첩 쓰기 | `/notebook/new` | 새 기록 작성                                             |
| 나눔      | `/share`        | 지인 관계와 나눔 이력 관리                               |
| 가격 조사 | `/prices`       | 소매 판매가·지역 조사가·도매 거래 조회                   |

작은 화면에서는 상단 ‘메뉴 열기’를 누른다. ‘사용 안내’는 메뉴 아래에 있다. ‘새 채팅’은 대화만 새로 시작하며 저장한 수첩·관심 지역·지인을 지우지 않는다.

## 2. 채팅으로 물어보기

입력란에 질문을 쓰고 전송 버튼을 누른다. 필요한 조건이 부족하면 답변에 이어서 알려주면 된다.

- “내일 오전 9시에 제주시랑 서귀포 중 어디가 좋을까?”
- “거기 말고 한라산남벽은 어때?”
- “그곳 거리뷰 링크도 보여줘.”
- “한라산남벽의 토지 소유 구분을 알려줘.”
- “2026년 5월 12일 서울가락 생고사리 도매 가격을 알려줘.”
- “내가 등록한 관심 지역을 보여줘.”

답변 위의 접힌 도구 내역에서 실제 조회 과정을 볼 수 있다. 가격표·지도·후보 비교는 ‘상세 보기’로 연다. 거리뷰는 답변의 링크를 눌러 연다. 응답 중에는 전송 버튼 자리에 있는 중지 버튼으로 멈출 수 있고, 연결이 끊긴 작업은 이어받을 수 있다.

답변에 맞는 후속 질문이 입력창 위에 표시된다. 누르면 같은 대화에서 질문을 이어간다. 상세 결과의 조건 변경·비교·수첩 쓰기도 기존 조회 조건을 이어받는다. 기록 변경은 미리보기와 확인을 거친다.

### 음성으로 입력하기

1. 마이크 버튼을 누르고 브라우저의 마이크 사용을 허용한다.
2. 한국어로 말한다. 듣는 동안 파형과 받아쓴 내용이 표시된다.
3. 말이 끝나거나 ‘음성 입력 마치기’를 누르면 받아쓴 내용이 입력란에 들어간다.
4. 내용을 고친 뒤 전송한다. 받아쓰기만으로 질문이 자동 전송되지는 않는다.

‘음성 입력 취소’ 또는 Escape를 누르면 녹음 전 초안을 유지한다. 지원하지 않는 브라우저에서는 키보드로 입력할 수 있다.

### 단축키

| 동작                 | Windows·Linux | macOS       |
| -------------------- | ------------- | ----------- |
| 빠른 메뉴            | Ctrl+K        | ⌘K          |
| 새 채팅              | Ctrl+Alt+N    | ⌘⌥N         |
| 채팅 입력란으로 이동 | Ctrl+/        | ⌘/          |
| 전송                 | Ctrl+Enter    | ⌘Enter      |
| 입력란 줄바꿈        | Shift+Enter   | Shift+Enter |

화면에는 접속한 운영체제에 맞는 키가 표시된다.

## 3. 나들이

상단 날짜는 지역별 날씨를 볼 날짜다. ‘지도 보기’를 펼치면 제주 지도와 지역별 날씨 목록이 함께 나온다. 지역 핀은 날씨 아이콘·기온·강수확률을 보여준다. 과거 날짜는 과거 날씨로 구분한다.

‘후보 비교로 이동’으로 비교 입력에 바로 갈 수 있다.

1. 후보별 지역·날짜·시각을 고른다. 후보는 2~4개다.
2. 비 적음·기온 온화·바람 약함의 우선순위를 정한다.
3. ‘후보 비교’를 누른다.
4. 순위별 기온·강수확률·바람을 보고, ‘비교 근거’를 펼쳐 이유와 최근 날씨를 확인한다. 카드에는 출처(기상청 단기예보 또는 Open-Meteo)·발표시각·대상시각이 표시된다.
5. 준비 목록에 항목을 추가·수정·삭제하고 체크한다.

상단 날씨 날짜를 바꿔도 작성한 후보는 유지된다. 비교 후 조건을 바꾸면 이전 결과에 적용된 조건과 갱신 필요 상태가 표시된다. 다시 ‘후보 비교’를 눌러 새 조건으로 조회한다.

## 4. 지역 탐색

지도에서 위치를 누르거나 ‘주소 검색’으로 찾는다. 열린 패널에 지역 이름·주소 또는 위치 메모·방문 날짜를 적고 저장 미리보기를 확인한다. 저장한 핀을 누르면 내용을 보거나 수정·삭제할 수 있다.

‘날씨 표시’를 켜면 주변 대표 지역의 날씨도 볼 수 있다. 현재 위치 기능은 제주 안에서는 해당 위치로 이동하며, 제주 밖이거나 위치를 얻지 못하면 제주 기본 범위를 사용한다.

## 5. 내 수첩

목록과 달력에서 기록을 찾는다. 날짜·동행 조건은 두 보기에서 공유하며, 조건을 지워 전체 기록으로 돌아갈 수 있다.

새 기록은 ‘수첩 쓰기’에서 채취 날짜·위치·메모·동행·수량과 단위를 적는다. 위치는 주소 검색이나 지도 핀으로 선택하고 읽기 쉬운 이름으로 바꿀 수 있다. 공개 날씨·가격 조회를 참고 자료로 연결할 수 있다.

저장 미리보기에서 날짜·위치·내용을 확인한 뒤 저장한다. 수정·삭제도 확인 화면을 거친다. 목록의 위치 보기는 저장한 장소를 확인하는 지도이며, 위치 변경은 기록 수정에서 한다.

## 6. 나눔

지인을 추가하고 나와의 관계·메모를 적는다. 지인을 선택하면 사람별 나눔 이력을 볼 수 있다.

나눈 날짜·분량·단위와 ‘예정’ 또는 ‘전달 완료’를 기록한다. 수첩 기록을 연결할 수 있고, 이력을 수정·삭제할 수 있다. 지인을 삭제해도 과거 나눔의 이름 기록은 남는다. 문자 작성·자동 발송 기능은 없다. 지인을 선택한 뒤 ‘공유 파일’을 누르면 그 사람의 나눔 기록을 텍스트 파일 1개로 미리 보고, 확인하면 브라우저가 내려받는다. 센터 설정에서 꺼져 있으면 버튼이 비활성화된다.

## 7. 가격 조사

- **소매 판매가:** 확인 시점이 있는 상품·규격·가격을 보고 외부 링크로 상품 페이지를 연다.
- **지역 조사가:** 지역·등급·생산지/도매지/소비지 기준의 조사가를 본다.
- **도매 거래:** 날짜·시장·생건을 고른다. ‘세부 조건’에서 등급·포장·단량·산지를 좁힐 수 있다.

‘상품 가격’과 ‘1kg 환산’으로 같은 기준의 가격을 비교한다. 배송비·쿠폰·환산식은 행을 펼쳐 확인한다. 도매 결과가 없으면 날짜·시장을 바꾸거나 세부 조건을 지울 수 있다. 세부 조건을 지워도 편집 중인 날짜·시장·생건 초안은 유지되며, 초안은 ‘가격 조회’를 눌렀을 때 적용된다.

채널을 다시 열면 남아 있는 조회 캐시를 재사용한다. 새 자료를 요청하려면 ‘새로고침’을 누른다.

## 8. 개인 기록 초기화

설정의 ‘개인 기록 초기화’는 확인 후 현재 세션의 저장 기록을 지운다. 대화만 새로 시작하려면 ‘새 채팅’을 사용한다.
