## 검증 방법과 경계

- 세 개 QA 호스트로 cookie·localStorage를 분리하고, 새 세션3개가 서로 및 기존 사용자 세션과 다름을 값 노출 없이 확인했다. Aside가 별도 브라우저 컨텍스트를 제공하지 않아 로컬 중계 주소를 사용했으며 실제 앱의 Host·Origin 허용 정책은 변경하지 않았다.
- 사용자 기록과 기존 localhost/127 세션은 수정하지 않았다. 합성 기록만 UI로 만들었고, QA 세션3개 종료200·종료한 세션 조회401·QA 탭0개·기존 사용자 세션 식별자 불변을 확인했다. 임시 중계 프로세스도 정지했다.
- Aside의 한국어 role 조회·일부 snapshot과 스크린샷에 도구 오류가 있어 관측한 CSS locator와 실제 키 입력으로 진행했다. 초기 빈 화면 의심은 실제 DOM·접근성 조상·콘솔이 정상이어서 제품 결함에서 제외했다. React 핸들러를 직접 호출해 결과를 만들지 않았다.
- 실제 마이크 녹음, Windows 설치, 부하 시험, 새 빌드·배포는 이 점검 범위가 아니다.
- 고정 기준 커밋의 변경 범위 게이트를 통과했다. API 관련 회귀와 Ruff, 웹 관련10파일95개 테스트와 Biome를 확인했다. 전체 앱 검사를 추가 실행하지 않았다.
