# 고사리잇 구현 결과

현재 상태: 최신 Linux AMD64 이미지의 빈 DB 설치·실행 경로와 아래 기능을 확인했다. 자연어 추천의 순위 불일치와 동일 공개 질문의 캐시 우회, QA 2건은 미해결이다. 제출 실행본·문서 준비와 이 품질 문제를 구분한다.

## 개발 목적

제주 고사리철에 날씨를 비교하고 경험·나눔을 기록하며 가격을 확인하는 일을 하나의 서비스로 연결했다. 대표 이용자인 58세 사용자를 기준으로 본문과 라벨은 16px 이상, 조작 영역은 44px 이상으로 구성했다.

## 에이전트와 데이터 처리

사용자 질문 → 모델의 도구 선택 → 서버 인자 검사 → 공개 자료 조회/캐시 → 품질 처리·집계 → 모델 답변과 상세 결과 순으로 실행한다. 답변은 SSE로 전송하고 실제 도구의 시작·완료·실패를 기록한다. 모델은 등록된 화면 구성요소와 후속 동작을 선택하며, 서버가 실제 조회 결과를 연결한다.

개인 자료는 세션별로 검색·저장한다. 모델에는 개인 검색의 종류와 건수만 전달하며, 기록 원문·별칭·개인 좌표는 전달하지 않는다. 작성·수정·삭제는 미리보기와 사용자 확인을 거친다.

공개 조회 결과와 응답 캐시는 PostgreSQL에 따로 보관한다. 조건·버전·해시·품질·유효기간을 검사하고 같은 요청은 병합한다. 대화 문맥이 없는 동일 공개 질문은 첫 모델 호출 전에 응답 캐시를 확인한다.

데이터별 실조회·표본·과거 재분석의 구분은 [데이터 활용 명세](data-usage.md), AI와 외부 서비스 구성은 [AI·의존성 목록](ai-and-dependencies.md)에 있다.

## 확인 범위와 남은 검증

- 조사가와 소매 상품은 확인 시점이 있는 표본·링크이며 실시간 상품 수집으로 표시하지 않는다.
- 원천의 정정 자동 감지, 도메인별 한국어 의미 캐시 오탐/미탐 평가, 전체 운영 분모에 대한 비용 절감률은 별도 인수·운영 평가 대상이다. 캐시 적중 한 건으로 전체 절감률을 산정하지 않는다.
- 마이크·브라우저 인식 서비스의 실제 전사 시험과 자동 API 대역 회귀를 구분한다. 최신 수동 확인 결과는 해당 실행 증거가 확보된 범위만 기재한다.
- 필수 원천의 활용 조건과 제출 형식은 대회 공지·운영진 답변을 기준으로 확인한다. 데이터·소프트웨어·모델의 라이선스는 각각 구분한다.

## 실행과 시연

[설치 매뉴얼](install-manual.md)에 따라 실행한 뒤 [사용 매뉴얼](user-manual.md)의 흐름으로 확인한다. 제출 소스에는 실제 `.env`·API 키·개인 기록 DB를 포함하지 않고 앱별 `.env.example`을 사용한다.

시연 흐름: 나들이 후보 비교 → 같은 대화에서 한라산남벽 질문 → 거리뷰 링크/소유 구분 → 관심 지역 또는 수첩 미리보기 → 지인 나눔 이력 → 가격 조회와 조건 변경.

## ZIP 추출본 실행

2026-11-08 소스 ZIP을 별도 디렉터리에 풀어 AMD64 이미지를 다시 만들고, 예제 설정으로 새 DB를 초기화해 UI/API readiness를 확인했다. 비밀은 ZIP에 없으므로 이 설치 검증은 외부 요청 꺼짐·모델 키 미설정 상태다. 이미지의 실행 내용 manifest는 `fd0c2e0c215208f9c4549086123c8cc0f800fce933d83e160ca64459bd7999b5`로 실제 모델 검증 이미지와 같다. 최종 ZIP은 매니페스트의 파일별 SHA256으로 실행 소스 일치를 대조한다.
