# AI 에이전트 실행과 비용 절감

기준은 제공된 「제주 고사리 채취 동행 AI 에이전트 개발 기획서」 14쪽의 Ⅲ장이다. 공개 질문의 조건 확인, 캐시 조회, 도구 선택·실행, 결과 설명을 대화에서 연결한다. 개인 기록은 로컬 검색·확인·승인 절차를 사용한다.

## 비용 절감 기준

응답 캐시는 첫 모델 호출 전에 조회한다. 동일 질문을 먼저 찾고, 의미 검색은 확정된 날짜·지역·가격 종류·규격 등 조건이 같으며 코사인 유사도가 **0.95를 초과**할 때만 사용한다. 최신성·출처·품질·버전·해시 검사도 통과해야 한다. 유사도만으로 다른 조건의 답을 반환하지 않는다.

공용 도구 결과와 대화 응답은 별도로 보관한다. 같은 공개 자료를 묻는 표현이 달라도 도구 결과를 재사용할 수 있다. 개인 기록·지인·정확 위치는 이 공용 캐시에 넣지 않는다.

동일 요청의 동시 실행과 한 작업 안의 중복 도구 호출을 줄인다. 모델에는 검증에 필요한 결과·시점·범위와 근거 참조를 전달하고 원표 전체를 반복해서 보내지 않는다.

고정 시스템 지시와 도구 정의의 순서를 유지하고, 한국 기준 날짜·시각은 뒤에 둔다. 모델은 GPT-6 Luna를 유지한다. 실제 입력·출력·추론·제공사 캐시 토큰과 호출 횟수를 기록한다. 사용량이 없으면 미확인으로 기록한다. 공용 응답 캐시 적중과 제공사 프롬프트 캐시 적중은 서로 다른 지표다.

확정 조건의 첫 모델 요청은 실행 가능한 도구로 선택 범위를 지정한다. 도구 결과를 받은 뒤 답변으로 이어져, 조회 전 답변을 반복해서 거절하며 모델을 재호출하는 비용을 줄인다. 전체 도구 정의는 그대로 두고 `tool_choice.allowed_tools`로 현재 실행 범위만 지정한다.

## 검증 기록

2026-11-07 개발 서버에서 실제 GPT-6 Luna와 aT 도매 조회를 실행하고, SSE의 도구 시작·완료·답변·종료 이벤트를 확인했다. DB 저장 오류를 수정한 뒤 같은 공개 결과를 새 프로세스와 다른 API 세션에서 `exact_hit`, 모델 호출 **0회**로 읽었다.

실제 웹에서는 “탐나오 제주 건고사리 100g 가격” 다음 “그럼 200g은?”을 입력해 대화 안에서 17,000원과 32,500원 표본을 확인했다. 경로는 `/`를 유지했고, 도구 내역 두 개는 기본 접힘 상태였다. 각 조회는 자료 도구 선택과 결과 답변의 모델 요청 두 번으로 완료했다. 이는 조사 시점이 있는 표본 조회이며 최신 상품 취득 시험과 구분한다.

프롬프트 캐시 토큰은 이 짧은 실조회에서 0이었다. 고정 접두부를 유지하는 구조와 캐시 적중 자체를 구분하며, 전체 서비스의 절감률은 산정하지 않았다. 모델·원천 장애, 재연결, 중지, 새 대화 경쟁은 외부 호출 없는 회귀로 확인했다. 빌드와 Windows·센터 설치 시험은 실행하지 않았다.

## 참고 자료

2026-11-07에 GitHub 원문, 공식 문서, X 게시물을 확인했다.

- [OpenAI 프롬프트 캐시](https://developers.openai.com/api/docs/guides/prompt-caching): 고정 접두부, 모델별 캐시 조건·쓰기 비용·사용량을 확인한다. 캐시 설정만으로 절감률을 단정하지 않는다.
- [Cloudflare Think 구현 문서](https://github.com/cloudflare/agents/blob/main/docs/think/index.md#prompt-caching): 매번 과거 문맥을 자르면 접두부 재사용이 깨질 수 있다.
- [Anthropic 비용 최적화 지침](https://github.com/anthropics/skills/blob/main/skills/claude-api/shared/cost-optimization.md): 입력·도구·루프의 불필요한 비용을 먼저 줄이고, 완료 품질과 전체 비용으로 평가한다.
- [Claude Code 개발자의 X 글, 2026-02-20](https://x.com/trq212/status/2024574133011673516): 날짜를 포함한 동적 정보와 도구 순서 변경이 캐시를 깨는 사례를 설명한다.
- [Claude 개발자 공식 X, 2026-05-19](https://x.com/ClaudeDevs/status/2056434423982444801): 캐시 미적중 원인과 토큰 비용을 확인하는 진단 기능을 안내한다.

짧은 대화마다 유료 요약을 추가하거나, 품질 평가 없이 모델을 바꾸거나, 소수의 도구에 별도 도구 검색 단계를 추가하지 않는다. 대화형 요청에 비동기 Batch를 적용하지 않는다. 절감률은 같은 작업의 품질·지연·실제 사용량을 비교한 뒤 산정한다.
