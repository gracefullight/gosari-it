# AI 에이전트 실행과 캐시

기준: 제공된 기획서와 이후 사용자 요청을 반영한 2026-11-08 제출 준비 소스. 최신 실행본 검증은 [구현 결과](submission-results.md)에 별도로 기록한다.

## 대화와 도구

`Coordinator.start_chat`은 개인 자료 경계를 확인한 뒤 원래 질문과 최근 대화를 `run_dialogue`에 넘긴다. 채팅에서 `FEATURE_HINTS`·`public_plan`의 키워드 분류로 메뉴를 고르지 않는다. 메뉴의 확정 조건 조회와 기존 준비 API는 호환 경로로 유지한다.

GPT-6 Luna가 `tool_choice=auto`로 도구·조건 질문·최종 답변을 선택한다. JSON Schema와 `build_public_spec`이 날짜·지역·시각·시장·규격과 출처를 검사한다. 잘못된 인자는 도구 오류로 돌려 모델이 복구할 수 있다. 완성된 모델 본문을 수치 검사 결과에 따라 고정 문장으로 바꾸지 않는다.

공개 도구는 지점 탐색, 과거·지역·현재·예보·나들이 비교, 도매·조사가·소매 가격, 필지 소유 구분을 조회한다. 거리뷰 도구는 공식 공개 지점으로 링크를 만들며 사용자가 클릭해 연다. 한 턴 안의 동일 도구·인자는 재사용하고 실제 실행한 도구만 내역으로 표시한다.

이전 조회의 tool 호출/결과 짝과 facts 식별자를 유지한다. 최근 최대 8개 사용자 턴의 완전한 대화 단위로 보관하고, 관리용 `respond` 호출/확인 중복은 제거해 최종 본문 한 번만 남긴다. 재시작 뒤 복구하는 클라이언트 이력은 허용된 user/assistant 역할·길이·자료 경계를 검사한다.

## 개인 조회와 변경

`search_personal_records`는 현재 세션의 수첩·관심 지역·지인·나눔을 검색한다. 모델에는 종류와 건수만 전달하며 원문·별칭·주소·개인 좌표·기록 ID는 전달하지 않는다. 실제 결과는 화면의 개인 API에서 읽는다.

`open_personal_form`은 작성·수정 요청에 기존 수첩·관심 지역·나눔 폼을 연다. 폼을 여는 것과 저장은 구분하며, 저장·수정·삭제는 미리보기·동의·실행 절차를 따른다. 개인 도구가 섞인 응답은 공용 응답·계획 캐시에 저장하지 않는다.

## SSE와 결과 UI

실제 제공사 텍스트 조각은 `assistant_delta`, 최종 본문은 `assistant_completed`로 보낸다. 도구에는 `tool_started`·`tool_completed`·`tool_failed`, 최종 작업에는 `done` 이벤트를 사용한다. 마지막 이벤트 ID로 이어받고 현재 세션의 작업만 조회한다.

모델의 `respond.ui`는 등록된 컴포넌트·후속 동작·결과 참조만 선택한다. 서버가 실제 자료에 연결한 json-render Spec을 구성하고 브라우저 Renderer가 표시한다. 여러 도구 결과와 캐시 복원 자료의 참조를 보존한다. 가격·날씨·비교·소유 구분은 ‘상세 보기’ 모달로 열고, 인사나 자료 없는 답변에는 빈 결과 박스를 만들지 않는다.

조건 변경·규격/날짜 비교·수첩 쓰기는 사용자가 클릭할 때 실행한다. 모델이 임의 HTML·화면 코드·가격표 값을 만들어 렌더링하는 경로는 사용하지 않는다.

## 캐시와 비용

| 계층                 | 처리                                                                                                                                 |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 첫 질문 계획 색인    | 원문 대신 해시와 검증된 단일 공개 QuerySpec을 저장. 한국 날짜·버전·TTL·무결성 검사 후 실제 응답 캐시 적중 때만 사용                  |
| 공용 응답 캐시       | 확정 조건 fingerprint와 exact 질문을 먼저 조회. 의미 검색의 기본 임계값은 0.95이며 조건이 같고 코사인 유사도가 이를 초과할 때만 사용 |
| 공용 조회 캐시       | 정규화된 공개 결과·근거·출처·해시·버전·TTL·품질을 PostgreSQL에 보관                                                                  |
| 동일 요청 병합       | 첫 질문 응답과 공개 원천 조회를 각각 singleflight로 병합. 중첩 잠금은 DB 연결을 재사용                                               |
| 제공사 프롬프트 캐시 | 고정 시스템·도구 순서를 유지하고 한국 날짜·시각을 뒤에 둠. 실제 cached-input 토큰으로 별도 계측                                      |

부분 자료·충돌·결측 필수 값·오류·개인 자료는 공용 캐시 재사용 대상에서 제외한다. 지도 화면의 날짜별 5분 캐시는 분석용 DB 캐시와 별도다.

기본 작업 토큰 예산은 64,000, 계획은 최대 8단계다. 실제 사용량을 차감하며, 사전 추정은 같은 작업에서 확인된 입력 사용량으로 보정한다. 사용량이 누락되면 미확인으로 기록하고 추가 모델 호출을 제한한다. 모델·원천 오류, 중지, 시간 초과는 작업 상태로 전달하며 실제 취득한 부분 자료를 보존한다.

입력·출력·추론·제공사 캐시 토큰, 호출 수를 기록한다. 전체 운영 분모의 비용 절감률과 달러 비용은 산정하지 않았다. 한 번의 응답 캐시 적중과 제공사 프롬프트 캐시 적중은 서로 다른 증거다.

로컬 임베딩은 기본 이미지에 포함하는 multilingual-e5-small의 고정 revision(`614241f622f53c4eeff9890bdc4f31cfecc418b3`)을 읽는다. 모델·토크나이저가 없으면 의미 검색은 사용하지 않고 exact 캐시와 키워드 검색을 유지한다. 개인 검색의 `mode=hybrid` 실제 반환과 의미 캐시의 적중은 해당 이미지에서 별도로 확인한다.

## 프롬프트 관리

[agent/prompts](../apps/api/src/gosari/agent/prompts/)의 UTF-8 Markdown을 `importlib.resources`로 읽는다.

| 파일                       | 용도                             |
| -------------------------- | -------------------------------- |
| `dialogue-system.md`       | 자유 대화·도구 선택·결과 설명    |
| `public-runtime-system.md` | 확정 공개 조건의 도구 루프       |
| `structure-system.md`      | 질문 구조화                      |
| `structure-tool-system.md` | 지정 분석 도구 호출              |
| `explain-system.md`        | 공개 결과 설명                   |
| `runtime-clock.md`         | 요청마다 계산하는 한국 날짜·시각 |

지시를 바꾸면 API를 재시작하고 응답 캐시의 프롬프트 버전을 갱신한다. 역할은 제주 고사리·날씨·지역·나들이·가격·수첩·관심 지역·나눔·서비스 이용을 돕는 에이전트다. 관련 없는 질문에는 짧게 범위를 안내한다.

## 공개 지점·거리뷰·소유 구분

제주데이터허브 578의 공식 지점 42곳과 대표 지역을 연결한 공개 카탈로그를 서버가 해석한다. 기본 지도는 대표 지역 12곳을 유지한다. 한라산남벽 `aws:965`는 공식 좌표 33.3524, 126.5330으로 조회한다.

거리뷰는 같은 공개 지점의 Google Maps panorama URL을 만든다. 토지 소유 구분은 브이월드 연속지적도에서 정확히 포함되는 필지를 찾고 `getPossessionAttr`의 분류명·기준월을 읽는다. 개인 소유자 이름·연락처는 응답·저장·모델 전달에서 제외한다.

브이월드 경로와 키 연결은 구현돼 있으며 이전 개발·페르소나 실행에서 한라산남벽의 국유지 분류·기준월 2024-12를 확인했다. 현재 제출 실행본에서 확인한 범위는 별도 결과 표를 따른다.

## 음성 입력

사용자가 마이크를 누르면 브라우저 SpeechRecognition을 `ko-KR`로 시작하고 Web Audio Analyser로 실제 신호를 표시한다. 발화 종료·최종 결과·인식 종료 때 받아쓰기를 기존 초안에 합친다. 입력란에서 수정한 뒤 사용자가 전송한다. 취소·화면 이탈·오류 때 인식과 마이크·오디오 자원을 정리한다.

별도 언어팩 설치나 받아쓰기 확인 버튼은 현재 흐름에 없다. 앱 서버로 음성을 업로드하지 않으며 브라우저 제공사 서비스가 원격 인식을 사용할 수 있다. 자동 API 대역 회귀와 실제 마이크·브라우저 서비스 시험은 [검증 결과](submission-results.md)에서 구분한다.

## 검증 기록

이전 개발 실행에서 실제 GPT-6 Luna의 도구 선택·후속 답변·SSE, 실제 aT 조회, 다른 API 세션의 exact-hit/모델 0회와 UI 복원, 개인 검색·작성 화면·다음 날 나들이·주제 밖 질문 안내를 확인했다. 한라산남벽 예보와 같은 지점의 거리뷰·소유 구분도 이전 실행에서 확인했다.

이 기록은 최신 이미지·빈 DB 검증을 대신하지 않는다. 최신 소스 기준·이미지 식별자·검사 수·수동 UI·실기기 범위는 [구현 결과](submission-results.md)에 모은다. 전체 서비스 절감률·기관 정정 자동 감지·도메인별 의미 검색 오탐/미탐 평가는 별도 평가 범위다.
