# AI 에이전트 실행과 비용 절감

기준은 제공된 「제주 고사리 채취 동행 AI 에이전트 개발 기획서」 14쪽의 Ⅲ장과 이후 사용자 지시다. 공개 질문과 최근 대화를 모델에 전달하고, 모델이 실제 인자를 가진 도구를 선택한다. 서버는 도구 인자·출처·결과 스키마를 검사하고 실제 조회를 수행한다. 생성된 답변을 수치 검증용 고정 문장으로 바꾸지 않는다. 개인 기록은 로컬 검색·확인·승인 절차를 사용한다.

채팅의 `FEATURE_HINTS`·`public_plan`·가격 지시어 분기는 실행 경로에서 제거했다. `start_chat`은 개인 자료 경계 확인 후 원래 공개 질문과 최근 대화만 작업에 넘긴다. `run_dialogue`는 `tool_choice=auto`로 도구 실행·조건 질문·최종 답변을 선택한다. 날짜·지역·시각·시장·규격은 JSON Schema와 서버 공개 게이트웨이로 검증한다.

모델의 응답 도구 호출과 결과도 짝을 유지해 다음 턴에 전달한다. 이전 조회 facts의 식별자를 보존하고, API 재시작 뒤에는 클라이언트가 보낸 최근 대화 본문 중 허용 역할·크기·공개 자료 경계를 통과한 메시지로 복구한다. 클라이언트가 제공한 system/tool 메시지와 개인 본문은 사용하지 않는다.

개인 조회와 작성도 모델이 구분한다. `search_personal_records`는 현재 세션에서 종류·검색어로 기록을 찾고, 모델에는 건수와 종류만 전달한다. 실제 본문·별칭·주소·좌표·식별자는 상세 모달을 열 때 같은 출처의 개인 API로 읽는다. `open_personal_form`은 등록·작성 요청에 기존 폼을 연다. 개인 도구를 쓴 턴은 공개 도구도 함께 실행했더라도 공용 응답·계획 캐시에 저장하지 않는다.

## 프롬프트 관리

프롬프트 원문은 `apps/api/src/gosari/agent/prompts/`의 UTF-8 Markdown 파일에서 관리한다.

| 파일                       | 용도                                       |
| -------------------------- | ------------------------------------------ |
| `dialogue-system.md`       | 자유 대화의 도구 선택과 응답               |
| `public-runtime-system.md` | 검증된 공개 조건으로 실행하는 도구 루프    |
| `structure-system.md`      | 공개 질문의 구조화                         |
| `structure-tool-system.md` | 확인된 공개 조건의 분석 도구 호출          |
| `explain-system.md`        | 조회 결과 설명                             |
| `runtime-clock.md`         | 요청마다 붙이는 한국 기준 날짜·시각 템플릿 |

`agent/prompts.py`는 `importlib.resources`로 파일을 읽고 끝 공백만 제거한다. Python 실행 모듈은 이 리소스를 참조한다. 날짜·시각은 기존처럼 KST로 계산해 마지막 템플릿에 채우고, 고정 지시 앞부분은 유지한다. 파일을 수정한 뒤 API를 다시 시작한다. 지시 내용이 바뀌면 공용 응답 캐시의 `PROMPT_VERSION`도 갱신한다.

현재 Hatch wheel 설정의 `src/gosari` 패키지 아래에 리소스를 둔다. 집중 회귀는 리소스 존재·UTF-8·실행 상수 연결·한국 날짜 경계·기존 개행을 확인하며 빌드는 실행하지 않는다.

## 비용 절감 기준

문맥 없는 동일 공개 질문은 첫 모델 호출 전에 도구 계획 색인과 응답 캐시를 확인한다. 계획 색인에는 질문 원문 대신 해시와 검증된 단일 공개 QuerySpec만 저장한다. 한국 날짜·버전·TTL·무결성을 검사하고 실제 응답 캐시가 적중할 때만 답변을 복원한다. 문맥이 있는 후속 질문은 이 색인을 쓰지 않는다.

확정 조건 조회의 의미 검색은 날짜·지역·가격 종류·규격 등 조건이 같으며 코사인 유사도가 **0.95를 초과**할 때만 사용한다. 최신성·출처·품질·버전·해시 검사도 통과해야 한다. 유사도만으로 다른 조건의 답을 반환하지 않는다.

공용 도구 결과와 대화 응답은 별도로 보관한다. 같은 공개 자료를 묻는 표현이 달라도 도구 결과를 재사용할 수 있다. 개인 기록·지인·정확 위치는 이 공용 캐시에 넣지 않는다.

동일 요청의 동시 실행과 한 작업 안의 중복 도구 호출을 줄인다. 모델에는 검증에 필요한 결과·시점·범위와 근거 참조를 전달하고 원표 전체를 반복해서 보내지 않는다.

고정 시스템 지시와 도구 정의의 순서를 유지하고, 한국 기준 날짜·시각은 뒤에 둔다. 모델은 GPT-6 Luna를 유지한다. 실제 입력·출력·추론·제공사 캐시 토큰과 호출 횟수를 기록한다. 사용량이 없으면 미확인으로 기록한다. 공용 응답 캐시 적중과 제공사 프롬프트 캐시 적중은 서로 다른 지표다.

동일한 첫 질문의 동시 실행은 질문 해시와 한국 날짜로 병합한다. 공개 도구 결과의 동시 취득도 별도로 병합한다. 메뉴에서 직접 확정한 QuerySpec은 기존 실행 경로를 사용하며, 자유 채팅의 도구 선택은 모델이 맡는다.

## 대화 UI

시스템 프롬프트는 고사리잇을 제주 고사리의 날씨·지역·나들이·가격 조회와 수첩·나눔 이용을 돕는 에이전트로 정의한다. 한국 기준 날짜와 시각은 매 요청에 전달하며, 원자료의 관측·조사 시점과 구분한다.

`respond.ui`에서 모델은 등록된 컴포넌트·동작과 조회 종류만 선택한다. 서버는 선택을 검사하고 실제 결과를 참조하는 json-render Spec을 만든다. 브라우저의 `@json-render/react` Renderer가 가격표·날씨 지도·비교·조건 폼을 표시한다. 모델이 만든 가격이나 HTML은 렌더링하지 않는다. 캐시는 답변과 UI 참조를 함께 보관하고 새 요청의 식별자로 복원한다.

상세 결과는 답변 아래의 ‘상세 보기’ 버튼으로 모달에서 연다. 자료가 없으면 이 버튼도 숨긴다. 도구 로그는 답변 위의 접힌 아코디언에 모은다. 답변은 `@gracefullight/markdown` 전처리와 React Markdown으로 강조·목록·표를 표시한다. 후속 동작은 클릭할 때만 실행한다. 조건 변경은 기존 조회 폼으로, 수첩 작성은 기존 초안·미리보기·승인 경로로 이어진다. 일반 인사에는 결과 박스를 만들지 않는다. 첫 답변을 기다리는 동안에는 점 애니메이션을 표시하고 입력창의 전송 버튼이 중지 버튼으로 바뀐다.

TanStack Hotkeys로 빠른 메뉴(`Ctrl/⌘ K`), 새 채팅(`Ctrl/⌘ Alt N`), 채팅 포커스(`Ctrl/⌘ /`), 입력창 전송(`Ctrl/⌘ Enter`)을 연결한다. 화면에는 해당 플랫폼의 키 하나만 표시한다. 한글 조합과 다른 모달·입력 필드를 존중하고 중복 전송을 막는다. 실제 macOS Aside에서 `⌘N`은 브라우저 새 창이 선점했다. DOM 이벤트를 전달하는 호스트에서는 기존 키도 받으며, OS 수준의 브라우저 예약키는 웹앱이 보장하지 않는다.

음성 입력은 사용자 클릭으로만 시작한다. 브라우저 SpeechRecognition의 한국어 전사를 받으며 Web Audio Analyser의 실제 신호로 파형을 그린다. 확인하면 원래 초안 뒤에 전사를 넣고, 취소하면 초안을 보존한다. 앱 백엔드로 음성을 업로드하지 않는다. 브라우저의 인식 서비스는 제공사 서버를 사용할 수 있다.

## 검증 기록

2026-11-07 개발 서버에서 실제 GPT-6 Luna와 aT 도매 조회를 실행하고, SSE의 도구 시작·완료·답변·종료 이벤트를 확인했다. DB 저장 오류를 수정한 뒤 같은 공개 결과를 새 프로세스와 다른 API 세션에서 `exact_hit`, 모델 호출 **0회**로 읽었다.

GenUI 추가 후 실제 도매 조회는 모델 요청 2회, 답변 조각 64개와 모델의 `PriceResults`·후속 동작 선택으로 완료됐다. 다른 API 세션에서 같은 질문을 실행하자 답변·UI가 함께 복원됐고 모델 호출은 0회였다. 브라우저는 기존 인사 아래에 빈 결과 박스가 생기지 않는 것도 확인했다.

음성 전사·파형·권한 오류·취소·자원 해제는 브라우저 API 대역으로 검증한다. 실제 마이크 녹음과 브라우저 인식 서비스의 전사 정확도는 자동 검증 범위에 포함하지 않는다.

실제 웹에서는 “탐나오 제주 건고사리 100g 가격” 다음 “그럼 200g은?”을 입력해 대화 안에서 17,000원과 32,500원 표본을 확인했다. 경로는 `/`를 유지했고, 도구 내역 두 개는 기본 접힘 상태였다. 각 조회는 자료 도구 선택과 결과 답변의 모델 요청 두 번으로 완료했다. 이는 조사 시점이 있는 표본 조회이며 최신 상품 취득 시험과 구분한다.

프롬프트 캐시 토큰은 이 짧은 실조회에서 0이었다. 고정 접두부를 유지하는 구조와 캐시 적중 자체를 구분하며, 전체 서비스의 절감률은 산정하지 않았다. 모델·원천 장애, 재연결, 중지, 새 대화 경쟁은 외부 호출 없는 회귀로 확인했다. 빌드와 Windows·센터 설치 시험은 실행하지 않았다.

## 최종 대화 회귀 (2026-11-07)

별도 테스트 세션의 실제 GPT-6 Luna 대화 4턴에서 내 지역 검색, 관심 지역 작성 폼, 다음 날 09:00 제주·서귀포 비교, 프로그래밍 질문 거절을 확인했다. 모델 호출은 각각 2·2·2·1회였다. 네 최종 응답 모두 `replacement=false`였고, 날씨 답변은 결과 1위인 서귀포와 일치했다. 개인정보가 없는 빈 테스트 세션을 사용했으며 사용자 기록을 변경하지 않았다. 저장된 지역 두 건을 조회하고 다른 세션에는 노출하지 않는 경로는 로컬 회귀로 확인했다. 한국어 Markdown과 달력 월·상세 모달·스크롤은 관련 UI 회귀로 확인한다.

사용자의 지시에 따라 상시 주의·면책 문구를 시스템 프롬프트에서 제거했다. 주제 밖 질문에 대한 짧은 안내는 유지하며, 완성된 모델 답변을 수치 검사 결과에 따라 고정 문장으로 바꾸지 않는다. 이전 템플릿 답변 캐시는 프롬프트 버전으로 분리한다.
